# Live mode: start from the meet page, alert N divers away

*2026-11-21*

The maintainer decided:

- Live mode starts from the meet page: a "Live now" section lists the boards running now. Home does not
  look up a followed diver's live event (that would load more pages).
- Two alerts per followed diver per round: one when they are N divers away, one when they are up next.
  N is 3 by default, set from 1 to 5 on the live screen, and kept on the phone (`alertAway`).
- No Settings screen for this.

How the board is read (approach A in `docs/superpowers/specs/2026-11-21-live-mode-design.md`): the live
service reloads the board page every 30 seconds and waits up to 10 seconds for the page's own script to fill
its table before reading. Picked because it is the read path the background test proved on the phone.
Re-reading only the table's own address is the fallback if the first phone run shows a problem.
