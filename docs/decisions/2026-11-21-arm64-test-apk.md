# The CI test APK is built for arm64 phones only (2026-11-21)

The `android` job passes `-PreactNativeArchitectures=arm64-v8a` to `assembleRelease`. Most of the
build time is native C++ code, compiled once per phone chip type; building one type instead of four
cuts that work to about a quarter.

What it costs: the test APK does not install on old 32-bit phones (`armeabi-v7a`) or on x86 emulators
without arm translation. Nearly every Android phone sold in recent years is arm64. Real releases (see
the release skill, filled in at milestone 7) should build every chip type.
